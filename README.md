# 高等数学 笔记

同济八版《高等数学》上册的复习笔记。第一章配 10 个课件、第二章已收 1–4 节 4 个课件，另有三角函数专题笔记和一份公式合集。

## 项目内容

- `高等数学-第一章-函数与极限.md`：第一章笔记，含第一至十节、本章总结与附录。
- `高等数学-第二章-导数与微分.md`：第二章笔记（第一至四节），含导数的概念与几何意义、左右导数、可导与连续、求导法则、高阶导数、隐函数与参数方程求导。
- `高等数学-专题-三角函数与反三角函数.md`：三角函数专题笔记，含六个三角函数的定义、图像、定义域与值域，反三角函数，以及单位圆中的三角函数线。
- `高等数学-公式合集.md`：跨章节的公式速查，含代数恒等式、数列求和、极限与等价无穷小、求导公式（含隐函数、参数方程与高阶导数）。
- `figures/`：专题笔记的插图；运行 `python3 figures/make_figures.py` 可重新生成。
- `高等数学_课件/`：14 个原始课件 PPT（第一章 10 个，第二章第 1–4 节 4 个）。

## 导出

用上游 note4Note 的 `export.py` 导出 PDF。插图在 `figures/`，需要让 xelatex 能按相对路径找到它们：

```bash
cd /path/to/notes
TEXINPUTS="$PWD//:" python3 ~/note4Note/tools/export.py --no-toc 高等数学-专题
```

（`~/note4Note` 为上游仓库的克隆位置。）产物写入 `output/`，已加入 `.gitignore`；不写笔记名则导出本目录的全部笔记。
