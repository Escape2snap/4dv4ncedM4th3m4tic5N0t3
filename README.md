# 高等数学 笔记

同济八版《高等数学》上册的复习笔记。第一章配 10 个课件，另有一份三角函数专题笔记。

## 项目内容

- `高等数学-第一章-函数与极限.md`：第一章笔记，含第一至十节、本章总结与附录。
- `高等数学-专题-三角函数与反三角函数.md`：三角函数专题笔记，含六个三角函数的定义、图像、定义域与值域，反三角函数，以及单位圆中的三角函数线。
- `figures/`：专题笔记的插图；运行 `python3 figures/make_figures.py` 可重新生成。
- `高等数学_课件/`：10 个原始课件 PPT。
